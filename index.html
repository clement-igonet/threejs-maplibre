threejs-maplibre

A three.js map engine for OpenStreetMap data, with MapLibre interop. Source and milestones on GitHub.

M1 tile foundations

  • Globe: OSM raster tiles on the WGS84 ellipsoid
  • Planar: flat Web Mercator map over Paris, same tile tree
  • Benchmark: the native engine (or 3d-tiles-renderer) over offline stub tiles; results land in window.__BENCH

The demos load tiles live from OpenStreetMap under its tile usage policy; please keep this page to light use. Append ?tiles=stub to a demo for the offline tile source used by CI.
